We release [WALL-E 2.0](https://huggingface.co/papers/2504.15785) ([code](https://github.com/elated-sawyer/WALL-E)) to improve the world model for LLM-based embodied agents. TL;DR: WALL-E 2.0 = Neuro-Symbolic World Model + MPC-based LLM Agent, where Neuro-Symbolic World Model = LLM + Complementary Symbolic knowledge (action rules, scene graph, knowledge graph) extracted from LLM errors in experiences.
